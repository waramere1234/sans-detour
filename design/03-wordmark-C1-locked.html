03 · Wordmark C1 — verrouillé · caret bulletproof

Le caret n'est plus un caractère typo. C'est une boîte CSS dimensionnée en ch + em.

Conséquence : identique sur iOS Safari, Android Chrome, desktop, print, et même si la police Plex Mono ne charge pas (fallback ui-monospace). Plus de risque de clipping sous baseline, plus de variation de largeur. Hauteur 0.10em, largeur 0.55ch, descendu de 0.05em sous la baseline visuelle. Animation respecte prefers-reduced-motion.

Le code à copier

/* CSS */
.sd-wordmark{
  font-family: "IBM Plex Mono", ui-monospace, monospace;
  font-weight: 500;
  line-height: 1;
  letter-spacing: -0.01em;
  display: inline-flex;        /* isole le caret du flow inline */
  align-items: baseline;
  white-space: nowrap;
}
.sd-wordmark .sd-slash { color: var(--ink-3); }
.sd-wordmark .sd-caret{
  display: inline-block;
  width: 0.55ch;
  height: 0.10em;
  background: var(--accent);
  margin-left: 0.18ch;
  transform: translateY(0.05em);
  animation: sd-blink 1s steps(1) infinite;
  flex: 0 0 auto;
}
@media (prefers-reduced-motion: reduce){
  .sd-wordmark .sd-caret { animation: none; }
}
@keyframes sd-blink { 50% { opacity: 0; } }

// JSX
<span className="sd-wordmark">
  sans<span className="sd-slash">/</span>détour<span className="sd-caret" aria-hidden="true"/>
</span>
