Tout ce qui n'est pas un écran nominal — pannes, attentes, copy, motion.

B · Animations — 5 motions, specs prêtes pour Framer Motion

1. Chip top 1 — flip200 ms · easeOut

🏆 LFI 71%
Quand le top 1 change, l'ancien chip opacity → 0, y +6, le nouveau entre opacity 0 → 1, y −6 → 0. 200 ms easeOut. Pas de bounce — registre sobre. Le pulse autour du dot reste constant pendant la transition.

2. Card swipe — drag & releaseFramer drag

RETRAITESReculer l'âge légal à 64 ans.10 mars 2024
drag="x", dragConstraints off, onDragEnd : si |x| > 100 && velocity > 200 → exit dans le sens du swipe (rotate ±14deg, x ±400, opacity 0, 250 ms). Sinon retour spring(stiffness 300, damping 28). Vertical down → idem axe Y, exit vers le bas.

3. Bars de ranking — stagger reveal600 ms · stagger 60

LFI71%
ECO66%
SOC62%
DEM42%
À l'ouverture du /result ou de l'overlay, chaque barre scaleX 0 → 1 avec transform-origin: left, 600 ms cubic-bezier(.2,.8,.2,1), stagger 60 ms. Le pourcentage compte de 0 à N en parallèle (useMotionValue + useTransform).

4. Overlay sheet — slide up320 ms · spring

RANKING EN DIRECT · 7 SCRUTINS COMPTÉS
Sheet y: 100% → 0, backdrop opacity 0 → 0.55 + blur 0 → 2px. spring(stiffness 240, damping 30). Sortie : reverse, 220 ms easeIn. Tap dehors ou drag down > 80 px → dismiss.

5. Caret du wordmark — blink1 s · steps

sans/détour
Caret = boîte CSS, pas un caractère. opacity 1 → 0 → 1, 1 s steps(1). Désactivé sous prefers-reduced-motion. Aucune autre animation au-dessus — c'est la seule "vie" de l'app au repos, exprès.

6. Reduced motion — fallbacka11y · WCAG

prefers-reduced-motion: reduce
→ pas de blink, pas de pulse,
pas de stagger, pas de spring.
Tout devient instantané ou crossfade 120ms.
Tous les @keyframes au-dessus sont enveloppés dans une media query qui les coupe. Les transitions Framer Motion utilisent useReducedMotion() pour passer à duration: 0.12, ease: "linear".

C.7 · Footer / méthodologieglobal
méthode · titreComment on calcule
méthode · 1Source : open data de l'Assemblée Nationale. Filtre : scrutins solennels uniquement.
méthode · 2Position d'un groupe : pour / contre / abstention si ≥ 70 % de ses votants effectifs s'y rangent. Sinon, "groupe divisé" — ce scrutin ne compte pas pour ce groupe.
méthode · 3Ton alignement par groupe = moyenne des écarts entre ton choix et la position du groupe, sur les scrutins comptés. Skip exclu.
donnéesAucune donnée personnelle envoyée. Tes choix vivent en local sur ton appareil. Pas de cookie, pas de compte, pas d'analytics nominatifs.
indépendanceSans Détour est un projet indépendant. Aucun lien avec un parti, un média, ou une institution. Code et données ouverts.
freshnessDonnées mises à jour automatiquement chaque semaine depuis l'Assemblée Nationale.

D · Tonalité — règles que je n'ai pas franchies

on dit
scrutin · groupe · alignement · vote · contre / pour / abstention · députés · AN · 17e légis. · partagé en local · source officielle
on ne dit pas
match · profile · quiz · viens swiper · politique fun · #engagé · ton vote secret · 100% précis · découvre ton vrai toi · IA
conventions
tutoiement, jamais "vous". · pas de point d'exclamation. · abréviations établies (PLFSS, AN). · chiffres en chiffres, pas en lettres. · emoji 🏆 toléré (chip top 1) — aucun autre.
