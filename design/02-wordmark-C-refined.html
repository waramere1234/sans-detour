02 · Wordmark C — micro-variantes & contextes

On verrouille C : 4 micro-variantes + 1 hybride A+C, puis C en contexte réel.

Trois questions à trancher : séparateur (slash, dot ou autre), curseur clignotant (oui / non / discret), accent (sur le séparateur ou ailleurs). L'orange reste un placeholder.

Micro-variantes de C

C1 · slash + caret blink
sans/détour_
Le plus "data-room vivante". Risque : le caret distrait dans un header. À garder pour l'écran cover éventuellement, pas partout.
C2 · slash seul (sobre)
sans/détour
Lecture immédiate, durable, scale partout (header 14px ou cover 64px). Recommandation par défaut. Le slash en gris-3 garde le rythme sans bruit.
C3 · slash accentué
sans/détour
Le slash devient l'élément de marque coloré (= favicon "/"). Plus signé, plus marketé. Risque : couleur de l'accent à valider — si on prend rouge ou bleu fort, ça change tout.
C4 · point final (mono)
sans détour.
Sans slash : juste le mono lowercase + le point coloré. Plus posé, moins "tech". Trade-off : on perd le mark "/" comme favicon.

Hybride A + C — pour comparaison

H · sans-serif lowercase + point
sans détour.
Plex Sans 600 lowercase + point. Plus "marque grand public", moins "outil de consultation". À mi-chemin entre A et C. Si C te semble trop techy à l'usage, c'est le repli logique.
