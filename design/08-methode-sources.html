01

D'où viennent les données

Les votes proviennent de l'open data officiel de l'Assemblée Nationale, exposé sur data.assemblee-nationale.fr. Ce sont les mêmes fichiers que ceux utilisés par les médias de référence et le service interne de l'AN. Aucune retranscription manuelle, aucune source secondaire.

Mise à jour automatisée toutes les semaines. La date de dernière sync est affichée ci-dessus.

02

Quels scrutins on garde

On filtre uniquement les scrutins solennels — ceux où chaque député doit afficher son vote nominalement. On exclut les scrutins ordinaires (où l'AN ne compte que les votes contestés) et les votes en commission. Le pool actuel : 87 scrutins de la 17e législature.

Pour ta session, on en tire 20 au hasard, en équilibrant les thèmes (économie, social, écologie, sécurité, institutionnel, international).

03

Comment on définit la position d'un groupe

Un groupe parlementaire compte plusieurs dizaines de députés qui ne votent pas toujours pareil. Pour résumer en une position unique :

Position du groupe sur un scrutin si ≥ 70 % des votants effectifs du groupe → pour / contre / abst. sinon → groupe divisé absents · non-votants → exclus du calcul

Un scrutin sur lequel un groupe est divisé ne compte pas pour ce groupe — pas pour toi non plus, dans cette comparaison. Ces scrutins sont indiqués en bas de chaque carte parti dans ton résultat.

04

Comment on calcule ton alignement

Pour chaque groupe, on regarde ce que tu as voté vs ce que ce groupe a voté, scrutin par scrutin :

Score d'alignement avec un groupe +1 par scrutin où ton vote = position du groupe +0,5 si l'un des deux s'abstient et l'autre vote 0 si désaccord net (pour vs contre) ÷ nombre de scrutins comptés (groupe non divisé, tu n'as pas skip) × 100 → pourcentage affiché

Le ranking apparaît dans l'app à partir du 5e scrutin compté — en dessous, les pourcentages bougent trop pour signifier quoi que ce soit.

05

Ce qu'on ne fait pas avec tes données

PAS DECompte utilisateur
PAS DECookie de tracking
PAS DEAnalytics nominatifs
PAS DEEnvoi serveur

Tes votes vivent dans le localStorage de ton navigateur. Si tu vides ton cache, ils disparaissent. C'est volontaire : on n'a aucun moyen technique de savoir comment tu as voté, ni qui tu es.

Le seul appel réseau, c'est le téléchargement initial du jeu de scrutins. Aucun POST.

06

Indépendance & financement

Sans Détour est un projet indépendant. Aucune affiliation avec un parti politique, un média, ou une institution publique. Le code est ouvert, les données sont ouvertes, la formule est publiée ci-dessus.

Hébergement payé sur fonds personnels. Pas d'annonceur, pas de sponsor, pas de don accepté pendant les 6 mois précédant un scrutin national.
